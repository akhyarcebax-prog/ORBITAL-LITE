# ORBITAL — Lite Edition

Website edukasi astronomi sederhana dengan empat halaman:
- `index.html` — Home
- `universe.html` — Tata Surya dan delapan planet
- `exploration.html` — Sejarah eksplorasi antariksa
- `discovery.html` — Fenomena kosmik dan kuis singkat

## Cara menjalankan
1. Ekstrak folder ZIP.
2. Buka folder `ORBITAL_Lite` di Visual Studio Code.
3. Buka `index.html` di browser (disarankan menggunakan ekstensi Live Server).
4. Pastikan koneksi internet tersedia untuk memuat Google Fonts dan gambar eksternal.

## Teknologi
HTML, CSS, dan JavaScript murni.

## Catatan
Gambar pada halaman menggunakan URL gambar eksternal. Jika ingin website dapat berjalan sepenuhnya offline, unduh gambar yang sesuai dan simpan ke folder `images`, lalu ganti URL gambar pada HTML.
